5. What is $DSPOINC?

$DSPOINC is the live in-ecosystem utility currency. You earn it by:

  • Playing ecosystem games and participating in community events
  • Completing quests, missions, and engagement loops
  • Using it for staking, future shop systems, ecosystem rewards, and Lab-related actions
  • Using it as the live power layer while the broader $SPOINC vision continues to develop

6. Genesis Lab

The Genesis Lab is the new progression core of Narrrf’s World. It loads verified Genesis NFTs, displays their real traits, and allows those traits to be upgraded over time.

  • 🧬 Verified NFT scan = identity layer
  • ⚙️ Trait upgrades = progression layer
  • 🔁 Upgrades stay attached to the NFT if ownership changes
  • ⏱️ Upgrades use timed research cycles with manual claim
  • 💰 DSPOINC can be used for instant finish actions

This moves Genesis NFTs toward persistent gameplay value instead of static ownership only.
