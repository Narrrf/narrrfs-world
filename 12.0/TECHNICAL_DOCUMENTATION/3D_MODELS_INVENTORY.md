## 🎮 Usage in Game

### Current Implementation
- **Player Character:** `Ninja.gltf` from `Monster 1/Big/glTF/`
- **Path:** `/textures/3d models/Monster 1/Big/glTF/Ninja.gltf`
- **Status:** Character loading is currently disabled (commented out) for debugging
- **Function:** `loadPlayerCharacter(modelPath)` in `three.js/main.js`

### Recommended Formats
- **For Characters:** Use **glTF** format (`.gltf` files)
  - Best performance in Three.js
  - Supports animations natively
  - Includes textures and materials

- **For Weapons:** Use **FBX** format (`.fbx` files)
  - Good for static models
  - Can be converted to glTF if needed

### Loading Models in Code

```javascript
// Load a character model
loadPlayerCharacter("/textures/3d models/Monster 1/Big/glTF/Ninja.gltf");

// Load a different character
loadPlayerCharacter("/textures/3d models/Monster 1/Big/glTF/Orc.gltf");

// Load a blob character
loadPlayerCharacter("/textures/3d models/Monster 1/Blob/glTF/Wizard.gltf");

// Load a flying character
loadPlayerCharacter("/textures/3d models/Monster 1/Flying/glTF/Dragon.gltf");
```

### Model Properties
- **Scale:** Models are scaled to `0.5, 0.5, 0.5` by default (adjustable)
- **Animations:** Models include Idle, Walk, Run animations (if available)
- **Shadows:** Cast and receive shadows enabled
- **Position:** Automatically synced with player collider position
- **Rotation:** Automatically rotates to face movement direction (third-person view)

## 🔧 Integration Notes

### Character Model System
- **Function:** `loadPlayerCharacter(modelPath)` in `three.js/main.js`
- **Animation System:** `AnimationMixer` for playing animations
- **Update Function:** `updatePlayerCharacter(delta)` in animate loop
- **Visibility:** Hidden in first-person view, visible in third-person view

### Model Loading
- **Caching:** Models are cached in `modelCache` Map
- **Cloning:** Models are cloned for multiple instances
- **Error Handling:** Falls back to simple player model if loading fails
