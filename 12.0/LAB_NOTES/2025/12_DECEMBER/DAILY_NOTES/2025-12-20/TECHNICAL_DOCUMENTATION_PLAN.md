## 📝 **DOCUMENTATION TEMPLATE**

Each game documentation includes:

### **Required Sections:**
1. ✅ Overview (Game description, features, status)
2. ✅ Architecture (System flow, technology stack)
3. ✅ Frontend Implementation (Files, key functions, code examples)
4. ✅ Backend API Integration (Endpoints, request/response, PHP code)
5. ✅ Database Schema (Tables, indexes, query examples)
6. ✅ Scoring System (Calculation, multipliers, flow)
7. ✅ Achievement System (If applicable - list all achievements)
8. ✅ Role-Based System (If applicable - multipliers, themes)
9. ✅ Admin Interface Integration (API endpoints, display code)
10. ✅ Code Examples (Complete working examples)
11. ✅ Testing & Verification (Checklist, SQL commands)
12. ✅ Critical Rules (Field mappings, important notes)

### **Key Information to Include:**
- ✅ **Database Field:** Correct field name (`discord_id`, `user_id`, `user_wallet`)
- ✅ **Table Name:** Exact table name
- ✅ **Game Identifier:** How game is identified in database
- ✅ **API Endpoints:** All endpoints used
- ✅ **Integration Points:** How it connects to Narrrfs World
- ✅ **Code Examples:** Working code snippets
- ✅ **Admin Integration:** How admin interface displays data
