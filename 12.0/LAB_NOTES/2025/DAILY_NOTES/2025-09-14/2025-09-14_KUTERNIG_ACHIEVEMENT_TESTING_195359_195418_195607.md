## 🚀 **MOBILE AUTHENTICATION TIMEOUT SOLUTION**

### **🔍 CRITICAL MOBILE ISSUE IDENTIFIED:**
Users report getting logged out during gameplay, especially on mobile devices.

#### **Root Causes:**
1. **Discord OAuth2 tokens expire in 1 hour** (3600 seconds)
2. **No refresh token mechanism** implemented
3. **Mobile browsers** clear localStorage/sessions aggressively
4. **Session cookies** may not persist across redirects on mobile

#### **Solutions Implemented:**

### **🔧 SOLUTION 1: Extended Session Lifetime**
- **Session lifetime:** Extended to 24 hours (86400 seconds)
- **Cookie lifetime:** Extended to 24 hours
- **Mobile compatibility:** Better session persistence

### **🔧 SOLUTION 2: Refresh Token Support**
- **Token expiration tracking:** Store `token_expires_at` timestamp
- **Refresh token storage:** Store Discord refresh token
- **Automatic refresh:** API endpoint for token renewal

### **🔧 SOLUTION 3: Mobile Authentication APIs**
