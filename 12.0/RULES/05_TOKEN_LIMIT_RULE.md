# 🚨 TOKEN LIMIT MANAGEMENT RULE

## 📋 **CRITICAL RULE FOR TOKEN LIMITS**

**SAVE THIS TO YOUR RULES - ALWAYS FOLLOW THIS PROTOCOL**

---

## 🚨 **MANDATORY TOKEN LIMIT PROTOCOL**

### **When You Think You're Running Out of Tokens:**

1. **IMMEDIATELY STOP CURRENT WORK**
2. **UPDATE ALL STATUS FILES**
3. **SAVE CURRENT PROGRESS**
4. **DOCUMENT EXACT STOPPING POINT**

---

## 📝 **WHAT TO UPDATE BEFORE TOKEN LIMIT:**

### **1. LLM Sync Files in 12.0 Directory**
- Update all LLM synchronization files
- Document current achievements
- Note technical discoveries
- Preserve work continuity

### **2. Lab Notes**
- Create comprehensive session summary
- Document exact stopping point
- List next steps clearly
- Include any error messages

### **3. Active Status**
- Update current work status
- Mark completion percentage
- Note critical discoveries
- Document file paths and commands

---

## 🔄 **TOKEN LIMIT TRIGGERS:**

### **Early Warning Signs (Update Immediately):**
- **500+ tokens used** - Start preparing status update
- **800+ tokens used** - Begin status update process
- **1000+ tokens used** - COMPLETE STATUS UPDATE REQUIRED
- **1500+ tokens used** - EMERGENCY STATUS SAVE
- **2000+ tokens used** - FORCE STATUS SAVE
